# BTC-Balance-Checker v2.5
BTC Balance Checker and Tracker. New Tracking BTC with Mass Checker up to 50 BTC  address.

Visit: https://dlordsociety32.github.io/BTC-Balance-Checker/

## Features:
- Supported Multi Language
- Supported Multi Currency
- Supported Multi Themes
- Using third party API like CoinGekco for live currency exchange
- Using third party BTC Explorer like Memepool for checking full history transactions

## Privacy:
- Not saving result of serches for outside server.
- No Private Keys ever needed or stored.
